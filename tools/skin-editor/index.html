    Select a group or click a preview sample. Shift-click a sample to edit its background.

    Colour picker · R · G · B · Alpha (0–1)

    Opt-in flat colour replaces selected tab artwork in widget defaults. Other buttons are unchanged; floaters with explicit tab images can override this.

    Toolbar layout

    Move commands between edges; reorder with arrow controls. Commands can appear only once.

    Full skin palette (advanced)

    RGBA values range from 0 to 1. Export uses a resolved palette snapshot; color aliases become independent values.

    Install and test

    The ZIP includes the new skin, a registration fragment, project JSON, and installation instructions. Close the viewer, back up settings, copy the new skin into its skins directory, and merge the registration entry into the existing skin registry. Select the new skin in Preferences and restart.

    Existing account toolbar settings override skin defaults. Replace that account's toolbar XML only after closing the viewer and making a backup. User color settings may also override skin colors. This editor never writes to the viewer or account settings.

    Friend name tags require the viewer's friend-colouring preference. Contact sets and per-avatar colours may take priority. Chat colours and overhead name tags are edited separately. Selected tabs use images; the custom tab option exports a flat replacement, while attention flash uses its own palette colour.

    Native assets. No upload. No external dependencies.
